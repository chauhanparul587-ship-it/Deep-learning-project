# 🧠 Deep Learning Regression Project

## 📌 Overview

This project is a **Deep Learning-based regression project** developed using Python and TensorFlow/Keras. The main objective is to build a neural network capable of learning patterns from structured/tabular data and predicting a continuous target variable.

The project follows a complete machine learning workflow, starting from data preprocessing and feature engineering to neural network development, model training, cross-validation, and performance evaluation.

---

## 🎯 Objective

The main objectives of this project are:

- Preprocess and prepare the dataset for Deep Learning.
- Handle categorical and numerical features.
- Apply one-hot encoding to categorical variables.
- Build a neural network using TensorFlow/Keras.
- Reduce overfitting using Dropout.
- Improve training stability using Batch Normalization.
- Train and validate the model.
- Evaluate the model using MSE and R² Score.
- Use K-Fold Cross-Validation to obtain a more reliable performance estimate.
